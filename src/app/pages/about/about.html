DigitalBookStore

by Renato Lins

A modern Angular SPA showcasing best practices in standalone components, signals-based state management, and a dark-themed "Midnight Library" visual design.

Tech Stack

  • Angular 21 Component framework
  • Signals Fine-grained reactive state
  • SCSS Design tokens & BEM styling
  • Vitest Unit testing
  • ESLint + Prettier Code quality
  • Husky Pre-commit hooks

Angular Practices

  • Standalone components — no NgModule
  • Lazy-loaded routes via loadComponent
  • @if / @for built-in control flow
  • input() signal API replacing @Input()
  • inject() instead of constructor injection
  • InjectionToken for app-wide configuration

Features

  • Searchable product catalogue
  • Shopping cart with quantity controls
  • Checkout modal (PIX / PayPal / Credit Card)
  • Instant download on purchase
  • Confetti animation on success
  • Fully responsive across all viewports
